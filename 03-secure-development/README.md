# 03 — Secure development

One file, one idea.

[`model-routing-change-management.md`](model-routing-change-management.md) makes model
routing a governed change type rather than an engineering change. Swapping or adding a
model touches the no-training commitment, the subprocessor disclosure and its
contractual advance-notice promise, the retention claim, and transfer posture — all at
once. A change reviewed only as code will pass review every time and still leave three
public commitments stale.

The gate that matters is the first one, because it is the only one attached to a
promise already made in writing.
